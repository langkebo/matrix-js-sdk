## 审查模板（基于已完成模块的最佳实践）

### 每个模块的审查步骤

1. **后端代码审查** (30%)
    - 审查路由文件（如 `device.rs`）
    - 识别所有接口、数据结构、错误码
    - 记录数据约束和验证规则
    - 分析业务逻辑和数据库操作

2. **契约文档优化** (40%)
    - 直接更新现有 `{module}.md`
    - 补充完整的请求/响应示例
    - 添加数据约束章节
    - 完善错误码映射
    - 添加数据库表结构（如需要）
    - 添加业务逻辑流程说明

3. **SDK 实现分析** (20%)
    - 审查 SDK 实现（如 `src/device/index.ts`）
    - 验证是否支持所有后端接口
    - 检查数据验证逻辑
    - 评估缓存和错误处理

4. **文档验证** (10%)
    - 验证文档与后端实现一致性
    - 生成评审总结
    - 记录变更清单
