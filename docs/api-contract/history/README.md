# 历史材料索引

> 说明: 本目录保存 `docs/api-contract` 的历史审查快照、专项评审报告、专项变更清单和阶段性增强版契约。当前主契约请优先以上一级目录中的模块主文档、`../README.md`、`../CHANGELOG.md` 与 `../VERIFICATION_REPORT.md` 为准。

## 使用原则

- 本目录文件仅用于追溯审查过程、专项整改记录和旧版补充说明。
- 若本目录中的描述与当前主契约冲突，以最新主契约文档和后端当前代码为准。
- 新一轮契约修订不再把“当前结论”写回本目录，而是统一更新上一级目录中的主契约文档。
- 历史正文中如果出现 `docs/api-contract/...` 这类旧路径文本，表示当时记录时的原始位置，不代表当前物理存放路径；当前应以本目录实际文件位置为准。
