## 状态定义

| 状态      | 含义                     |
| --------- | ------------------------ |
| Open      | 风险尚未开始处理         |
| 进行中    | 缓解措施正在执行         |
| Mitigated | 缓解措施已实施，风险降低 |
| Closed    | 风险已完全消除           |

## 更新规则

- 每周更新一次状态、阻塞项、到期风险。
- P0 风险逾期超过 3 天必须升级到架构周会处理。
- 逾期自动升级机制：
    - 若 `状态` 不为 `✅ Mitigated/Closed` 且当前日期晚于 `截止时间`，该条目自动升级为 `P0`。
    - 自动升级后需在 1 个工作日内同步到架构周会与执行台账，并在更新历史追加升级记录。
    - 自动升级条目在关闭前不得降级优先级。
